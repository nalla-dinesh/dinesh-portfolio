## Case files worth opening

### 🧠 [AIOS](https://github.com/nalla-dinesh/AIOS)
Eight-agent system with LangChain / LangGraph, Groq + Ollama routing, ChromaDB retrieval, hallucination detection and Dockerized services.  
**Why it matters:** agent orchestration is only useful when routing, memory, retrieval and evaluation are connected.

### 🕵️ [insiderlens](https://github.com/nalla-dinesh/insiderlens)
Explainable ledger alerts with FastAPI, PostgreSQL, React, Cytoscape and NetworkX.  
**Why it matters:** an alert should come with evidence, not just a score. Synthetic benchmark numbers are not real-world accuracy.

### 📍 [walkmate-v2](https://github.com/nalla-dinesh/walkmate-v2)
Flutter + Kotlin foreground service, GPS filtering, Haversine distance, OEM battery guidance and crash recovery.  
**Why it matters:** mobile reliability is a systems problem, not just a UI problem.

### 🧾 [kajibook](https://github.com/nalla-dinesh/kajibook)
Offline-first Flutter billing with integer-paise money handling, FIFO allocation, Drift and Riverpod.  
**Why it matters:** financial arithmetic and local persistence deserve careful engineering.

### 🚚 [VALVIX](https://valvix.vercel.app)
Freelancing studio co-founded in 2025. 10+ Android apps shipped across healthcare, fitness, retail and business.  
**Why it matters:** shipping client products teaches constraints that demo projects do not. Client source is private under NDA.
