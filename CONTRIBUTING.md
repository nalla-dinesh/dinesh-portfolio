# Contributing

This is a personal portfolio and profile repository, but issues and suggestions are welcome.

## Setup

```bash
npm ci
npm run dev
```

## Before opening a pull request

```bash
npm run check
npm test
npm run test:e2e
```

## Content rules

- Keep claims evidence-backed.
- Label founder-reported or NDA work clearly.
- Do not add fake metrics, copied templates or unverified badges.
- Do not commit secrets or private client assets.

## Style

- TypeScript strict mode is enabled.
- Keep animations accessible: respect reduced motion and provide a static fallback.
- Keep the GitHub profile SVGs self-contained.
